# Notes

Loose, working notes — not polished writing, not part of the thesis. This is the scratch layer between "idea in your head" and "properly written up in `docs/`". Nothing here needs to be tidy; the point is having it in the repo (searchable, dated by git history) instead of scattered across a notes app, WhatsApp, or your head.

- `scratchpad.md` — running log of random thoughts, half-formed ideas, things to check later, design decisions and why you made them.
- `meeting-notes.md` — quick notes from supervisor meetings (Mandy, Robyn).

Add more files here freely (e.g. `component-shortlist.md`, `questions-for-supervisors.md`) — this folder doesn't need to stay to just these two.
