# Report

LaTeX source of the EEE4022S final report, built from the UCT Electrical Engineering thesis template.

Build with pdfLaTeX from this folder:

```sh
latexmk 0_main
```

`0_main.tex` is the main file. Chapters are `1_intro.tex` to `11_FurtherWork.tex`, the appendices follow, and references are in `thesis.bib`. The signature image on the declaration page is not included in the repository, so that page will show a missing image.
